All four meet the targets.

## Fixed in this pass

- **Dark-mode contrast.** Navy bands (footer, proof band, process) used the
  dark-mode navy `#2f5c90`, lifted so navy buttons stand out on a dark page;
  faint white text on it fell to 3.0–4.3:1. Dark navy is now `#284f7c`
  (white/70 at 5.05:1, buttons still distinct from the page), faint footer and
  source text is white/75, and the footer brand is 20px bold so its amber
  "Co." meets the large-text bar. Light mode already passed.
- **Decorative numerals** (01, 02, 03) are drawn with `::before` so they are
  decoration, not text that fails contrast by design.

## Known, not a fault

- **Best practices 96** on every page: the Vercel Analytics and Speed
  Insights scripts 404 on a local server and load normally on Vercel.
- **Homepage LCP** varied between 3.0s and 3.2s on earlier runs with render
  delay, not load time. Not caused by the font (`display: swap`) or a
  hydration mismatch (none logged). Judge it from Vercel Speed Insights field
  data after deploy rather than lab runs.

## How to re-run

```sh
npm run build && npm run start -- -p 4511
CHROME_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  npx lighthouse@12 http://localhost:4511/ --only-categories=performance,accessibility,seo,best-practices
```
